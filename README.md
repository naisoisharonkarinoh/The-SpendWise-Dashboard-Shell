# The SpendWise Dashboard Shell

This repository contains small utilities and examples for the SpendWise Dashboard prototype.

## expense_manager.py

- A simple, menu-driven command-line expense manager backed by an in-memory list of dictionaries.
- Run with:

```powershell
python expense_manager.py
```

Features:
- Add expenses (amount, description, category) with safe input validation.
- List all expenses.
- Filter expenses by category.
- Summary: total, count, average, largest, and per-category totals.
